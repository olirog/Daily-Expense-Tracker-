# Daily Expense Tracker 💰

A simple command-line expense tracker written in Python. The application allows users to manage their daily expenses, set a budget limit and calculate spending statistics.

Prosty konsolowy menedżer wydatków napisany w Pythonie. Aplikacja pozwala zarządzać codziennymi wydatkami, ustawiać limit budżetu i obliczać statystyki wydatków.

---

## 🇬🇧 English

### Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Calculate average expenses
- Set a budget limit
- Get warnings when exceeding the budget
- Delete individual expenses
- Clear all expenses
- Choose between English and Polish language

### Technologies

- Python 3

### How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```

### Language Support

The application supports two languages:
- English 🇬🇧
- Polish 🇵🇱

Choose your preferred language when starting the program.

### Purpose

This project was created to practice Python programming fundamentals, including lists, loops, conditional statements, functions, user input and basic mathematical operations.
